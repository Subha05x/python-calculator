# Python Calculator

A simple calculator built using Python that performs basic arithmetic operations. This is my beginner Python project, created to practice functions, conditional statements, and user input.

## Features

- Addition (+)
- Subtraction (-)
- Multiplication (*)
- Division (/)
- Division-by-zero error handling
- Supports choosing operations using numbers or symbols

## Requirements

- Python 3

## How to Run

## How to Run

1. Clone this repository:

   ```bash
   git clone https://github.com/Subha05x/python-calculator.git
   ```

2. Navigate to the project directory:

   ```bash
   cd python-calculator
   ```

3. Run the program:

   ```bash
   python3 calculator.py
   ```
